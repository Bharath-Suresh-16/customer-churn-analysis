#  Customer Churn Analysis with Python

This project explores a telecom company's customer data to identify patterns that lead to churn. The analysis is done using Python, pandas, matplotlib, and seaborn — focusing on actionable insights for business decision-making.

##  Dataset
Telco churn dataset (customer-level data including contract type, charges, services, and churn status).

##  Key Questions:
- What types of customers are more likely to churn?
- Does contract type, internet service, or monthly charges influence churn?
- Can we identify high-risk churn groups?

##  Exploratory Data Analysis:
- Churn distribution across demographics and services
- Visualizations: Contract Type vs Churn, Monthly Charges vs Churn, Tenure vs Churn, Internet Type vs Churn
- Insights with business implications

##  Key Insights:
- Customers with **month-to-month contracts** are more likely to churn.
- **High monthly charges** correlate with higher churn.
- Most churn happens in the **first 6 months**.
- **Fiber optic users** churn more often than DSL or no internet.

##  Tools Used:
- Python (pandas, seaborn, matplotlib)
- Jupyter Notebook (in VS Code)
